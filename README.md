# Teller

Tellers voor Sip, Saf en al de rest.

👉 **https://arnauddc807.github.io/teller/**

## Op je telefoon zetten

Open de link op je gsm en:

- **iPhone** — deel-knop onderaan in Safari → *Zet op beginscherm*
- **Android** — menu (⋮) in Chrome → *App installeren*

Daarna staat Teller tussen je apps en werkt hij ook zonder internet.
